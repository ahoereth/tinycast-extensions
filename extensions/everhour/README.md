# Everhour Time Tracking

## 🚀 Getting Started

You will need your API Token:

1. `Navigate` to "My Profile" (https://app.everhour.com/#/account/profile)
2. `Scroll` to "Application Access"
3. `Copy` "API Token"
4. `Paste` in Extension Preferences
